# Project Selection — SoftSolutions Client Portal

## The problem

SoftSolutions is a web development / digital agency serving SMB clients. Project
status and quotations are currently communicated over WhatsApp and email, with no
shared source of truth. This causes:

- Repeated "how's my project going?" messages that eat into admin time
- No clear history of milestones completed or quotations accepted
- A less professional impression next to clients who expect a digital experience

## Objective

Build a functional client-facing portal that centralizes project status and
quotation tracking between SoftSolutions and its clients, replacing informal
messaging with a single, shared source of truth.

### Specific objectives

1. Model clients, projects, milestones, and quotations under SoftSolutions' two
   commercial modalities (Proyecto / Suscripción).
2. Implement authentication with two roles (ADMIN, CLIENT) so each client only
   ever sees their own data.
3. Build an admin panel to manage clients, projects, milestones, and quotations.
4. Build a read-only client panel showing progress, milestones, and payment status.
5. Validate the system with functional, security, and performance testing.

## Expected impact

- Less administrative time spent answering status questions manually
- A more professional, differentiated experience for SMB clients
- A reusable base that can scale to more clients without a redesign

## Justification

This project solves a real, current operational problem for SoftSolutions while
also satisfying the university assignment's requirement to run a complete agile
software development cycle: project selection, planning, iterative development,
review cycles, and QA.
